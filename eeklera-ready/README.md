## 🌐 КАК ЗАГРУЗИТЬ НА СЕРВЕР

### Способ 1: FileZilla (САМЫЙ ПРОСТОЙ) ⭐

1. Скачай FileZilla: https://filezilla-project.org/
2. Узнай данные у своего хостинга:
   - **Host:** ftp.твойхостинг.ru
   - **Логин:** твой_логин
   - **Пароль:** твой_пароль
   - **Порт:** 21

3. Подключись в FileZilla
4. Слева - твой компьютер, справа - сервер
5. Найди папку `/public_html` или `/www` справа
6. **ПЕРЕТАЩИ ВСЕ ФАЙЛЫ** из этой папки туда →

**ГОТОВО!** ✨

---

### Способ 2: Панель хостинга

1. Войди в панель управления (Timeweb/Beget/Reg.ru)
2. Найди "Файловый менеджер"
3. Открой `/public_html`
4. Нажми "Загрузить файлы"
5. Выбери ВСЕ файлы из этой папки
6. Жди загрузки

**ГОТОВО!** ✨

---

### Способ 3: VS Code

1. Открой эту папку в VS Code
2. Установи расширение "SFTP"
3. Ctrl+Shift+P → "SFTP: Config"
4. Введи данные хостинга
5. Правый клик → "Upload Folder"

**ГОТОВО!** ✨

## 🔧 НАСТРОЙКА ДОМЕНА

### Если домен УЖЕ куплен:

**В панели хостинга:**
1. Найди раздел "Домены"
2. Добавь свой домен (например eeklera.ru)
3. Укажи папку: `/public_html`

**У регистратора домена:**
1. Найди DNS настройки
2. Добавь A-записи:
   ```
   @ → IP-адрес твоего хостинга
   www → IP-адрес твоего хостинга
   ```
3. Сохрани

⏳ **Подожди 2-6 часов** - домен заработает!

Почти все хостинги дают **БЕСПЛАТНЫЙ SSL**:

2. Выбери свой домен

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Страницы не открываются
→ Проверь что файлы в `/public_html`, а не в подпапке

### Фото не грузятся
→ Убедись что папка `assets/` загружена

### Меню не работает на телефоне
→ Проверь что `mobile-nav.js` загружен

### Всё сломалось
→ Удали всё и загрузи заново
