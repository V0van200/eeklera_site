## Что готово

- **14 страниц** — главная, биография, актёрка (+ детали проектов), музыка (+ детали релизов), стриминг, модельная, события, хронология, медиа/шоу, связи, источники, галерея, контакты, поиск.
- **Дизайн-система** — газетная типографика (Geist + Instrument Serif + Geist Mono), палитра кремовый/чернила/винный/охра, чипы статусов, общая боковая навигация.
- **Поиск** — клиентский (без сервера), индексирует фильмографию, релизы и события. Запрос можно открыть как `search.html?q=ревизоры`.
- **Реальные фото** — 12 снимков, переданных автором, размещены в `assets/photo-01.jpg ... photo-12.jpg`. Главный портрет `assets/hero.jpg`.
- **Источники** — все факты на сайте имеют статус и сноску на источник (Кинопоиск, Кино-Театр, Filmtoolz, BandLink, Telegram, Twitch).

## Технические заметки для разработчика

- Все страницы — статический HTML + один общий `data.js` и `styles.css`. Без сборки.
- Боковая навигация инжектируется через `data.js` (компонент `EEKChrome.SideNav`).
- Карточки фильмов / музыки рендерятся клиентом из массивов в `data.js` — чтобы добавить запись, достаточно дописать объект в `acting` или `music`.
- Фотогалерея — простой grid + lightbox с навигацией стрелками / Esc.
- Поиск — линейный, по 3 полям (`title`, `desc`, `role`/`label`). Расширить можно добавив `tags`.
